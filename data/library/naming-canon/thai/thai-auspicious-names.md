## สรุปสั้น (ฟันธง)

1. **หลักตั้งชื่อไทยของแท้ที่มีตำรารองรับ = "ทักษาปกรณ์" (ผูกกับ "วันเกิด" ไม่ใช่ธาตุ)** — แบ่งพยัญชนะไทยเป็น 8 หมู่ (วรรค) วางบน 8 ตำแหน่ง (ภูมิ) หมุนตามวันเกิด เลือกอักษรจากตำแหน่งดี เลี่ยง "กาลกิณี" เด็ดขาด ตารางครบด้านล่าง ตรวจสอบตรงกันหลายแหล่ง
2. **การผูก "ธาตุ/ราศี → เสียง/อักษร" โดยตรง ไม่พบตำราคลาสสิกรองรับ** — ธาตุ (ดิน/น้ำ/ลม/ไฟ) และราศี เป็นเรื่อง "ทำนายนิสัย/โหราศาสตร์" ไม่ใช่ตำราตั้งชื่อ การจับคู่ธาตุ↔อักษรที่เห็นตามเว็บพาณิชย์เป็นการตีความสมัยใหม่ (ผ่านฐานกรณ์เสียงสันสกฤต) ไม่ใช่คัมภีร์ — บอกตรงๆ (ดูหัวข้อ 2)
3. **คลังคำมงคล 110+ คำ** พร้อมรากศัพท์บาลี-สันสกฤต + หมวด (ทรัพย์/ปัญญา/อำนาจ/เมตตา/สุขภาพ-อายุ/ความรัก) คำที่รากศัพท์ยังไม่ชัด **ทำเครื่องหมาย ⚠️ กำกับ ไม่แต่งเดา**

## 1. หลักทักษาปกรณ์ (ตำราหลัก — ผูกกับวันเกิด)

### 1.1 พยัญชนะไทย 8 หมู่ (อัฐเคราะห์ / วรรค)

| หมู่ (นาม) | ดาวประจำ / วัน | พยัญชนะในหมู่ |
|---|---|---|
| ครุฑนาม | อาทิตย์ (๑) | **อ** และสระทั้งปวง (อะ อา อิ อี อุ อู เอ โอ ฯลฯ) |
| พยัคฆนาม | จันทร์ (๒) | **ก ข ค ฆ ง** |
| ราชสีหนาม | อังคาร (๓) | **จ ฉ ช ซ ฌ ญ** |
| โสณนาม | พุธ กลางวัน (๔) | **ฎ ฏ ฐ ฑ ฒ ณ** |
| นาคนาม | เสาร์ (๗) | **ด ต ถ ท ธ น** |
| มุสิกนาม | พฤหัสบดี (๕) | **บ ป ผ ฝ พ ฟ ภ ม** |
| คชนาม | ราหู / พุธ กลางคืน (๘) | **ย ร ล ว** |
| อัชชนาม | ศุกร์ (๖) | **ศ ษ ส ห ฬ ฮ** |

> หมายเหตุ: บางตำราสลับชื่อ "นาค/โสณ" กันเล็กน้อย แต่ตัวพยัญชนะในหมู่และดาวประจำหมู่ตรงกัน — ยึดตามตารางนี้ (myhora + theluckyname + boonbaramee ตรงกัน)

### 1.2 แปด "ตำแหน่ง" (ภูมิทักษา) และความหมาย

| ลำดับ | ตำแหน่ง | ความหมาย (ใช้ส่งเสริมด้านใด) |
|---|---|---|
| ๑ | **บริวาร** | บุตร คู่ครอง ลูกน้อง เพื่อนพ้อง คนรอบข้าง |
| ๒ | **อายุ** | ชีวิต สุขภาพ การดำเนินชีวิต อายุยืน |
| ๓ | **เดช** | อำนาจ วาสนา บารมี เกียรติยศ ตำแหน่ง |
| ๔ | **ศรี** | โชคลาภ เสน่ห์ สิริมงคล เงินทอง |
| ๕ | **มูละ** | ทรัพย์สิน มรดก หลักฐานความมั่งคั่ง |
| ๖ | **อุตสาหะ** | ความเพียร ความอดทน ความสำเร็จจากแรงตน |
| ๗ | **มนตรี** | ผู้ใหญ่อุปถัมภ์ ที่ปรึกษา ความสำเร็จจากผู้ช่วย |
| ๘ | **กาลกิณี** | อุปสรรค ทุกข์โศก ศัตรู — **ห้ามใช้เด็ดขาด** |

**วิธีวางวง:** เอา "บริวาร" ทับหมู่พยัญชนะประจำ "วันเกิด" ของเจ้าของชื่อ แล้วไล่ อายุ→เดช→ศรี→มูละ→อุตสาหะ→มนตรี→กาลกิณี เวียนขวาไปตามลำดับวงทักษา คือ
**อาทิตย์ → จันทร์ → อังคาร → พุธ(กลางวัน) → เสาร์ → พฤหัส → ราหู(พุธกลางคืน) → ศุกร์** แล้ววนกลับ
(ผลลัพธ์: กาลกิณี = หมู่ที่อยู่ "ก่อนหน้า" วันเกิดหนึ่งช่องในวงเสมอ)

### 1.3 ตารางกาลกิณี (อักษรต้องห้าม) ตามวันเกิด — ⭐ สำคัญสุด

| วันเกิด | **อักษรกาลกิณี (ห้ามใช้ในชื่อ)** |
|---|---|
| **อาทิตย์** | ศ ษ ส ห ฬ ฮ |
| **จันทร์** | สระทั้งปวง + อ (อะ อา อิ อี ...) |
| **อังคาร** | ก ข ค ฆ ง |
| **พุธ (กลางวัน)** | จ ฉ ช ซ ฌ ญ |
| **พุธ (กลางคืน)/ราหู** | บ ป ผ ฝ พ ฟ ภ ม |
| **พฤหัสบดี** | ด ต ถ ท ธ น |
| **ศุกร์** | ย ร ล ว |
| **เสาร์** | ฎ ฏ ฐ ฑ ฒ ณ |

> ตารางนี้คำนวณจากตำแหน่ง "ก่อนวันเกิดหนึ่งช่อง" และ **ตรวจสอบตรงกับผลค้นหา sanook/lemon8/boonbaramee ทั้ง 8 วัน** — ใช้ implement ได้เลย
> ข้อยกเว้นที่ตำราไทยยอมรับ: อักษรกาลกิณีปรากฏใน "นามสกุล" ได้ (79hora) และสระที่จำเป็นต้องผสมเสียงไม่นับเป็นกาลกิณีเต็มตัวในทางปฏิบัติของบางสำนัก — ให้ระบบเตือนเฉพาะ "พยัญชนะต้น/ตัวสะกดเด่น"

### 1.4 ตำแหน่งที่ "ควรเน้น" ตามเป้าหมายผู้ใช้ (ต่อยอดใน app)

- อยากรุ่งเรือง/มีอำนาจ → เน้นอักษรหมู่ **เดช**
- อยากมีเสน่ห์/โชคลาภ/เงิน → เน้น **ศรี**
- อยากมั่งคั่ง/มีหลักฐาน → เน้น **มูละ**
- อยากมีคนอุปถัมภ์ → เน้น **มนตรี**
- (วิธีหา: วางวงตามข้อ 1.2 แล้วดูว่าหมู่ใดตกตำแหน่งนั้นสำหรับวันเกิดนั้นๆ)

## 2. เรื่อง "ธาตุ / ราศี" — พูดตรงตามหลักฐาน

**ข้อเท็จจริง:** ค้นแล้ว **ไม่พบตำราตั้งชื่อคลาสสิกที่ผูก "ธาตุ (ดิน/น้ำ/ลม/ไฟ) → หมู่พยัญชนะ" โดยตรง**
- ธาตุ/ราศี ในของไทยเป็นเรื่อง **โหราศาสตร์ทำนายนิสัย** และ **แพทย์แผนไทย (ธาตุเจ้าเรือน)** — คนละคัมภีร์กับการตั้งชื่อ
- หลักตั้งชื่อของแท้ผูกกับ **"วันเกิด" ผ่านทักษา** (ข้อ 1) ไม่ใช่ธาตุ
- การจับคู่ "ธาตุ↔อักษร" ที่เห็นตามเว็บ/แอปพาณิชย์เป็น **การตีความสมัยใหม่** ผ่านหลักฐานเสียง (ฐานกรณ์) ของสันสกฤต ไม่มีคัมภีร์รองรับตรงๆ **อย่าเคลมว่าเป็นตำรา**

**สะพานที่ "พอมีเหตุผลทางภาษา" (ใช้เป็นฟีเจอร์เสริม ระบุชัดว่าเป็นการตีความ):**
สัทศาสตร์บาลี-สันสกฤตจัดพยัญชนะตาม **ฐานกรณ์ (ที่เกิดเสียง)** ซึ่งบางสำนักโยงเข้าธาตุได้ดังนี้ (เป็น mapping เชิงตีความ ไม่ใช่คัมภีร์):

| ฐานเสียง (สันสกฤต) | พยัญชนะ | ธาตุที่มักโยง |
|---|---|---|
| กัณฐชะ (คอ) | ก ข ค ฆ ง + สระ อ อา | ธาตุไฟ/อากาศ |
| ตาลุชะ (เพดาน) | จ ฉ ช ฌ ญ + อิ อี ย ศ | ธาตุลม |
| มุทธชะ (ปุ่มเหงือก) | ฏ ฐ ฑ ฒ ณ ร ษ | ธาตุ (แข็ง) |
| ทันตชะ (ฟัน) | ต ถ ท ธ น ล ส | ธาตุน้ำ/ดิน |
| โอษฐชะ (ริมฝีปาก) | ป ผ พ ภ ม + อุ อู ว | ธาตุดิน/น้ำ |

> ⚠️ ตารางนี้ให้ใช้เป็น "แนวเสนอเสียง" เท่านั้น และในแอปควรเขียนกำกับว่า "การตีความสมัยใหม่จากฐานเสียงสันสกฤต ไม่ใช่ตำราตั้งชื่อ" — เพื่อไม่ผิดกฎซื่อตรงต่อคัมภีร์
> **คำแนะนำ implement:** ให้ทักษา (วันเกิด) เป็น "ตัวกรองหลัก/บังคับ" ส่วนธาตุ/ราศี เป็น "โทนเสริม" เท่านั้น

### 2.1 ราศี → ธาตุเจ้าเรือน (ข้อเท็จจริงโหราศาสตร์ ใช้จัดโทนได้)

- **ธาตุไฟ:** เมษ · สิงห์ · ธนู
- **ธาตุดิน:** พฤษภ · กันย์ · มังกร
- **ธาตุลม:** เมถุน · ตุลย์ · กุมภ์
- **ธาตุน้ำ:** กรกฎ · พิจิก · มีน

## 3. คลังคำ/พยางค์มงคลไทย (110+ คำ พร้อมรากศัพท์ + หมวด)
