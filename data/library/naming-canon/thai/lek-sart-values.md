## 0. ที่มาของศาสตร์ (สรุปสั้น)

เลขศาสตร์ไทย (การถอดอักษร→ตัวเลข แล้วรวมหาความหมาย) **ไม่มีคัมภีร์ต้นฉบับเล่มเดียว/ผู้แต่งคนเดียวที่ชี้ชัดได้** จากการค้น — เป็นความรู้พื้นบ้านที่สืบทอดผ่านครูบาอาจารย์โหราศาสตร์ไทยหลายสำนัก ราก
ของมันคือ **ระบบนพเคราะห์/ทักษา (ดาว 9 ดวง)** ในโหราศาสตร์ไทย โดยจัดพยัญชนะ-สระ-วรรณยุกต์เข้ากลุ่มดาวทั้ง 9 แล้วให้ค่าตามลำดับดาว 1–9 (อาทิตย์=1 ... เกตุ=9)

- เว็บไทยหลายแห่งอ้างเพิ่มว่าแนวคิด "ถอดอักษรเป็นเลข" มีรากจาก **บาบิโลน/พีทาโกรัส (Pythagorean numerology)** แล้วไทยนำมาปรับเข้ากับดาวนพเคราะห์ — เป็นคำกล่าวลอย ไม่มีการอ้างตำราต้นฉบับที่ตรวจสอบได้
- **สรุปตรงๆ: หา "ตำราต้นฉบับ + ผู้แต่ง" ที่ยืนยันได้ไม่เจอ** สิ่งที่เจอคือ "ระบบมาตรฐานที่หลายสำนักใช้ตรงกัน" ซึ่งเพียงพอต่อการทำสูตรคำนวณ

## 1. ตารางค่าอักษร (พยัญชนะ / สระ / วรรณยุกต์) = เลขอะไร

ระบบนี้ให้ค่าอักษร **1–9 ตามกลุ่มดาวนพเคราะห์** ตารางด้านล่างคือระบบที่ **สองแหล่งตรงกัน** (theluckyname + ซินแส.com) จึงถือเป็น "ระบบมาตรฐาน/สำนักหลัก"

| เลข | ดาว | พยัญชนะ | สระ | วรรณยุกต์ / อื่นๆ |
|-----|------|---------|------|------------------|
| **1** | อาทิตย์ | ก ด ท ถ ภ ฤ | อา, อุ, อำ | ไม้เอก ( ่ ) |
| **2** | จันทร์ | ข ช ง บ ป | เอ, แอ, อู | ไม้โท ( ้ ) |
| **3** | อังคาร | ฆ ต ฑ ฒ ฃ | — | ไม้จัตวา ( ๋ ) |
| **4** | พุธ | ค ธ ญ ร ษ | โอ, อะ, อิ | ไม้หันอากาศ ( ั ) |
| **5** | พฤหัสบดี | ฉ ณ ฌ น ม ห ฮ ฎ ฬ | อึ | — |
| **6** | ศุกร์ | จ ล ว อ | ใอ (ใ) | — |
| **7** | เสาร์ | ซ ศ ส | อี, อือ | ไม้ตรี ( ๊ ) *(บางสำนักจัดตรีไว้ที่นี่)* |
| **8** | ราหู | ย พ ฟ ผ ฝ | — | ไม้ไต่คู้ ( ็ ) |
| **9** | เกตุ (พระเกตุ) | ฏ ฐ | ไอ (ไ) | ตัวการันต์ ( ์ ) |

### หมายเหตุ/ความต่างระหว่างสำนัก (สำคัญ — อย่าใช้เงียบๆ)
- **ตรงกันเกือบทั้งหมด** ระหว่าง 2 แหล่งที่ตรวจ — ระบบนี้ค่อนข้างเสถียร
- จุดที่ **ไม่ตรง/ต้องระวัง**:
  - **วรรณยุกต์ตรี ( ๊ )** — theluckyname ระบุอยู่กลุ่ม 7, ซินแส.com ไม่ได้ระบุตรีชัด → **ยังไม่ฟันธง** ควรยืนยันเพิ่ม
  - อักษรหายาก **ฮ ฎ ฬ** — ซินแส.com จัดไว้กลุ่ม 5 (แหล่งแรกไม่ครบ) → ใช้ตามซินแส.com ได้แต่ควร cross-check สำนักที่ 3
  - **ฃ (ขวด), ฅ (คน)** อักษรเลิกใช้ — เจอ ฃ ในกลุ่ม 3 (ซินแส.com) ส่วน **ฅ ยังหาค่าไม่เจอ**
  - **ค่าตัวเลขอารบิก 0–9** ที่ใช้พิมพ์ในทะเบียน/เบอร์: โดยทั่วไปเลข = ค่าตัวมันเอง (1=1 ... 9=9, 0=0) แต่ **หน้าที่ตรวจไม่ได้ระบุชัด** → ยังไม่ยืนยัน
  - **สระบางตัว** (แอ, โอะ, เอือ, ฯลฯ) ไม่ได้ระบุครบทุกรูป → บางสำนักถอดตามเสียงสระหลัก ควรทำตารางแมปสระให้ครบก่อน implement

> ⚠️ **ก่อนนำไป implement ในโค้ด**: ควรหา "สำนักที่ 3" (เช่น ตำราเล่มพิมพ์ของ อ.โหราศาสตร์) มายืนยันจุดที่ยังไม่ตรง โดยเฉพาะ **วรรณยุกต์ตรี, สระที่ขาด, และค่าเลขอารบิก**

## 4. สัญญาอนุญาต / ลิขสิทธิ์ (⚠️ ระบบจะขึ้น Play Store — ตอบตรงๆ)

### 4.1 ค่าอักษร = เลข (ตารางข้อ 1) → **ใช้เชิงพาณิชย์ได้ ปลอดภัย**
- เป็น **ระบบ/วิธีการ/ข้อเท็จจริง** (system/method/facts) ไม่ใช่งานสร้างสรรค์ → **ลิขสิทธิ์คุ้มครองไม่ถึง** (กฎหมายลิขสิทธิ์ไม่คุ้มครองระบบ วิธีการ และข้อเท็จจริง)
- อีกทั้งเป็น **ภูมิปัญญาพื้นบ้าน (traditional/folk knowledge)** ที่ใช้กันแพร่หลายหลายสำนัก → ไม่มีเจ้าของลิขสิทธิ์รายเดียว
- ✅ **นำตารางค่าอักษรไปใช้/คำนวณในแอปได้เลย** ไม่ต้องขออนุญาต ไม่ต้องเครดิต

### 4.2 ชื่อเรียกสั้นๆ ของผลรวม (เช่น "ยอดเสน่ห์", "เทพีแห่งโชค") → **ใช้ได้**
- เป็นวลี/ชื่อสั้นมาก (ไม่กี่คำ) → **สั้นเกินกว่าจะมีลิขสิทธิ์** (short phrases/titles ไม่ได้รับความคุ้มครอง)
- ✅ ใช้เป็น label ในแอปได้

### 4.3 คำบรรยายความหมายแบบเป็นประโยค/ย่อหน้า → **มีลิขสิทธิ์ ห้ามลอกทั้งประโยค**
- ข้อความบรรยายยาวๆ ที่เจ้าของเว็บเขียนเอง = **งานวรรณกรรม มีลิขสิทธิ์**
- 🔴 **ต้องเรียบเรียงใหม่ด้วยคำของเราเองทุกประโยค** (แบบที่ทำในข้อ 2.1) หรือใช้ข้อเท็จจริงพื้นฐาน (เลขนี้คือดาวอะไร ดี/ร้าย) ซึ่งเป็นข้อเท็จจริง ไม่ผูกลิขสิทธิ์
- 🔴 **ห้าม** copy-paste ย่อหน้าจาก central / berded / boonbaramee ฯลฯ ลงแอปตรงๆ

### สรุปฟันธงสำหรับ Play Store
1. **สูตรค่าอักษร + ตรรกะคำนวณผลรวม** = ใช้ได้เต็มที่ ปลอดภัย
2. **ป้ายชื่อผลรวมสั้นๆ** = ใช้ได้
3. **คำอธิบายความหมาย** = ต้องเขียนใหม่เองทั้งหมด (เขียนคลัง copy ของ hourkey เอง อ้างอิงความเชื่อพื้นบ้านเป็นข้อเท็จจริง) — ห้ามลอก
