# 姓名判断 (Seimei Handan) — ศาสตร์ทำนายชื่อญี่ปุ่นจากจำนวนขีด (画数 kakusū)

> เอกสารอ้างอิงต้นฉบับสำหรับ hourkey — ศาสตร์ทำนายชื่อแบบญี่ปุ่น
> วันที่ค้นคว้า: **24 กรกฎาคม 2026** (ค.ศ. 2026-07-24)
> ⚠️ hourkey **มี engine 姓名學 จีน (五格) อยู่แล้ว** — เอกสารนี้เน้นจุดที่ญี่ปุ่น **ต่างจากจีน** เป็นพิเศษ (ดูส่วน §6)

## 0. ภาพรวม + ที่มา (สำคัญต่อเรื่องสัญญาอนุญาต)

- ศาสตร์นี้ชื่อ **姓名判断 (せいめいはんだん / seimei handan)** = "การตัดสินชื่อสกุล" คำนวณจาก **จำนวนขีด (画数 kakusū)** ของตัวคันจิในชื่อ
- ระบบกระแสหลักในญี่ปุ่นคือ **熊崎式 (Kumazaki-shiki / แบบคุมะซากิ)** ริเริ่มโดย **熊崎健翁 (Kumazaki Kenō, 1881–1961)** จากหนังสือ **『姓名の神秘』 (ค.ศ. 1929)**
- วิธีหลักเรียก **五格剖象法 (ごかくぼうしょうほう / gokaku bōshō-hō)** = แยกชื่อออกเป็น "五格 (5 格 / go-kaku)" 5 ค่า
- **ประเด็นที่มา (ต้องพูดตรง — ตำราขัดกันเอง):**
  - แหล่งญี่ปุ่นหลายเจ้าบอกว่ารากมาจาก **จีน** (五行説 ของขงจื๊อ, ใช้ 康煕字典 เป็นเกณฑ์นับขีด) → คือ **ระบบเดียวกับ 五格剖象法 จีน** ที่คุมะซากินำเข้ามาเผยแพร่
  - แต่ **Wikipedia ญี่ปุ่น** ระบุว่ารูปแบบ "五格" นี้เป็น *"รูปแบบต้นตำรับญี่ปุ่นที่จัดระบบช่วงปลายเมจิ–ต้นโชวะ"* (a Japanese original format)
  - 👉 **ข้อสรุปที่ปลอดภัย:** แนวคิด 五格 + ตาราง 81 เลข **ญี่ปุ่นกับจีนใช้ร่วมกัน/มีรากเดียวกัน** แต่ **รายละเอียดกฎการนับขีด และการให้ความหมายบางเลข ต่างกัน** (ดู §6)

## 1. วิธีคำนวณ 五格 (5 grids) — ครบถ้วน + ตัวอย่างจริง

สมมติชื่อ **田中 太郎 (Tanaka Tarō)** — นามสกุล 田中, ชื่อ 太郎
จำนวนขีด: 田 = 5, 中 = 4, 太 = 4, 郎 = 9

| 格 (grid) | สูตร | ความหมายที่ปกครอง | ตัวอย่าง 田中太郎 |
|---|---|---|---|
| **天格 (tenkaku / ฟ้า)** | ผลรวมขีดของ **ทุกตัวในนามสกุล** | ดวงบรรพบุรุษ/วงศ์ตระกูล (ไม่ค่อยใช้ทำนายตัวบุคคลเดี่ยวๆ เพราะเปลี่ยนไม่ได้) | 田5 + 中4 = **9** |
| **地格 (chikaku / ดิน)** | ผลรวมขีดของ **ทุกตัวในชื่อตัว** | ช่วงต้นชีวิต (วัยเด็ก–หนุ่มสาว), ธาตุแท้ภายใน | 太4 + 郎9 = **13** |
| **人格 (jinkaku / คน)** | ขีดของ **ตัวสุดท้ายของนามสกุล + ตัวแรกของชื่อ** | **สำคัญที่สุด** — บุคลิก, ดวงคน/สังคม, วัยกลางคน | 中4 + 太4 = **8** |
| **外格 (gaikaku / นอก)** | ขีดของ **ตัวแรกนามสกุล + ตัวสุดท้ายชื่อ**  ⟨= 総格 − 人格⟩ | ดวงสังคม/ภายนอก, ความสัมพันธ์กับคนรอบข้าง | 田5 + 郎9 = **14** (= 22−8) |
| **総格 (sōkaku / รวม)** | ผลรวมขีด **ทั้งชื่อ** ⟨= 天格 + 地格⟩ | **สำคัญรองจาก 人格** — ดวงตลอดชีวิต, บั้นปลาย | 9 + 13 = **22** |

**ลำดับความสำคัญ:** 人格 (สูงสุด) > 総格 > 地格/外格 > 天格

**ถ้าค่าเกิน 81:** ใช้ค่าที่ได้จาก **(ค่า − 80)** หรือหารด้วย 81 เอาเศษ (ถ้าเศษ = 0 ให้ใช้ 81) — แหล่งญี่ปุ่นบางเจ้าเขียนว่า "หาร 81 เอาเศษ 0→81", บางเจ้าใช้ −80. โดยปกติชื่อจริงแทบไม่เกิน 81 อยู่แล้ว

## 2. กฎ 霊数 (reisū / "เลขวิญญาณ" = บวก 1) — สำหรับชื่อ/สกุลตัวเดียว

- เมื่อ **นามสกุลหรือชื่อมีตัวเดียว** ให้เติม **霊数 = 1** ในตำแหน่งที่ขาด เพื่อให้สูตร 人格/外格 ทำงานได้
- ตัวอย่าง: **林 一 (Hayashi Hajime)** — 林=8, 一=1 (สกุล 1 ตัว, ชื่อ 1 ตัว)
  - 外格 = 霊数1 (หน้าสกุล) + 霊数1 (หลังชื่อ) = **2**
- ⚠️ **ข้อควรระวัง:** 霊数 ใช้กับ **天格 / 地格 / 外格** เท่านั้น — **人格 กับ 総格 ไม่บวก 霊数** (คำนวณจากขีดจริงเท่านั้น)
- ⚠️ กฎนี้ **แตกต่างกันตามสำนัก (流派)** — บางสำนักไม่ใช้ 霊数 เลย → เป็นจุดที่ต้องเลือก policy ให้ชัดใน engine

## 3. กฎการนับขีด (画数) — 旧字体 vs 新字体

- **แนวกระแสหลัก (熊崎式) ใช้ 旧字体 / 正字 (ตัวเต็มโบราณ) ตามพจนานุกรม 康煕字典** ไม่ใช่ตัวย่อสมัยใหม่ (常用漢字/新字体)
- นับ **บุชุ (部首 / รากอักษร) ตามจำนวนขีดของตัวต้นกำเนิด** — จุดนี้คือหัวใจที่ทำให้ต่างจากการนับขีดปกติ:

| รากอักษร (ในรูปย่อ) | นับปกติ | นับแบบ 姓名判断 (ตามต้นกำเนิด) |
|---|---|---|
| 氵 (さんずい, น้ำ) | 3 | **4** (มาจาก 水) → 洋=10, 河=9 |
| 艹 (くさかんむり, หญ้า) | 3 | **4** → 花=8 |
| 辶 (しんにょう, เดิน) | 3 | **4** → 道=13 |
| 礻 (しめすへん) | 4 | **5** (มาจาก 示) → 神=10 |
| 忄 (りっしんべん, ใจ) | 3 | **4** (มาจาก 心) |
| 扌 (てへん, มือ) | 3 | **4** (มาจาก 手) |
| 月 (にくづき, เนื้อ) | 4 | **6** (เมื่อมาจาก 肉) |
| ⺩ (おうへん, หยก) | 4 | **5** (มาจาก 玉) |

- ตัวอย่างตัวเต็มโบราณ: 恵→**惠**(12), 国→**國**(11), 沢→**澤**, 広→**廣**
- **เลขจีน 一〜十 นับตามค่า:** 一=1, 二=2, 三=3 … 十=10 (ไม่ได้นับตามรูปขีดจริง)
- ⚠️ **ญี่ปุ่นมีสำนักมากกว่า 30 สำนัก** — บางสำนักใช้ 新字体 (ตัวย่อปัจจุบัน), บางสำนักใช้ 旧字体 → **ผลทำนายต่างกันได้** ต้องเลือก policy (ค่าปริยายที่นิยม = 旧字体/康煕字典)

## 4. การนับขีด ひらがな / カタカナ (kana)

- เมื่อชื่อเขียนด้วยคานะ ให้นับ **ตามจำนวนขีดที่เขียนจริง** (แต่ค่าตามสำนักต่างกันได้)
- ตัวอย่างค่ามาตรฐาน (สำนัก 吉元式 / ทั่วไป):
  - **ひらがな:** あ=3, い=2, う=2, え=3, お=4 …
  - **カタカナ:** ア=2, イ=2, ウ=3, エ=3, オ=3 …
  - หมายเหตุ: เสียงเดียวกัน ひらがな กับ カタカナ **ขีดต่างกัน** → ดวงต่างกัน
- **เครื่องหมายพิเศษ:**
  - **濁点 ゛ (dakuten) = +2 ขีด** → が = か(3) + 2 = 5
  - **半濁点 ゜ (handakuten) = +1 ขีด** → ぱ = は(4) + 1 = 5
  - 長音 ー (ลากเสียง), ตัวเล็ก (っ ゃ ), เครื่องหมายซ้ำ — **ถ้าใช้ในชื่อ ให้นับรวม** (ค่าตามสำนัก)
- ⚠️ **ค่าขีดคานะไม่มีมาตรฐานกลาง** — แต่ละเว็บ/สำนักให้ต่างกัน → engine ต้องล็อกตารางของตัวเองและระบุที่มา

## 6. ⭐ ต่างจาก 姓名學 จีนตรงไหน (สำคัญที่สุด — hourkey มี engine จีนแล้ว)

| หัวข้อ | จีน (姓名學 / 五格剖象法) | ญี่ปุ่น (熊崎式 seimei handan) |
|---|---|---|
| **แนวคิด 五格** | 天/人/地/外/総 — **เหมือนกัน** (มีรากร่วม/คุมะซากินำเข้า) | **เหมือนกัน** — สูตรคำนวณตรงกัน |
| **ตาราง 81 เลข** | 81數理 (อิง 河洛/五行 9×9) | ใช้ตาราง 81 **เดียวกันเป็นฐาน** |
| **เกณฑ์นับขีด** | ใช้ **康煕字典 / ตัวเต็ม (繁体) เสมอ** (มาตรฐานเดียว ค่อนข้างล็อก) | **ถกเถียง 旧字体 vs 新字体** — 30+ สำนัก, บางเจ้าใช้ตัวย่อสมัยใหม่ → **ผลต่างกันได้** |
| **คานะ (ひらがな/カタカナ)** | ไม่มี (จีนใช้ฮั่นจื้อล้วน) | **มีเฉพาะญี่ปุ่น** — ต้องมีตารางขีดคานะ + กฎ 濁点/半濁点 |
| **霊数 (บวก 1)** | จีนมีแนวคิดคล้าย (假成数) แต่เรียกต่างกัน | เรียก **霊数**, กฎ +1 กับชื่อ/สกุลตัวเดียว (บางสำนักไม่ใช้) |
| **ความหมายบางเลข** | มาตรฐานตาม 81數理 คลาสสิก | **บางเลขให้คะแนนต่าง** ตามสำนัก โดยเฉพาะเลขก้ำกึ่ง |
| **เลขร้ายเฉพาะผู้หญิง (寡婦運/女難数)** | จีนมีแนวคิด 孤寡数 แต่ไม่เด่น | **ญี่ปุ่นเน้นมาก** — เลข **21, 23, 29, 33, 39** เป็น **มงคลสำหรับชายแต่ร้ายสำหรับหญิง** ("寡婦運/未亡人運" — พลังแกร่งเกินไป ข่มคู่/ดวงสามี) — นี่คือ **จุดต่างเด่นชัดของญี่ปุ่น** |
| **การใช้งานจริง** | เน้นตั้งชื่อมงคล (取名) | เน้นทั้งตั้งชื่อ (名づけ) + ทำนายดวง |

**สรุปสำหรับ engine hourkey:**
1. **โครงคำนวณ 五格 reuse จาก engine จีนได้เลย** (สูตรตรงกัน) — แต่ต้อง **แยกตารางความหมาย 81 เลข** เพราะบางเลขต่างกัน
2. **ต้องเพิ่มตารางขีดคานะ + กฎ 濁点(+2)/半濁点(+1)** — จีนไม่มี
3. **ต้องเพิ่มกฎ 霊数** และ **กฎเลขร้ายเฉพาะเพศหญิง (21/23/29/33/39)** — เป็นเอกลักษณ์ญี่ปุ่น
4. **ต้องเลือก policy นับขีด** (旧字体 = ค่าปริยายนิยม) และล็อกตารางบุชุ (氵=4, 艹=4, 辶=4 ฯลฯ)

## 7. ⚠️ สัญญาอนุญาต (Play Store)

- **วิธีคำนวณ 五格 + การจำแนกเลข 吉/凶 = ระบบ/ข้อเท็จจริง (fact/method)** → **ใช้ได้** ลิขสิทธิ์ไม่คุ้มครองสูตร/ระบบ (熊崎式 เผยแพร่ตั้งแต่ 1929, method อยู่ใน public domain)
- **prose คำบรรยายความหมายแต่ละเลข ของเว็บที่ค้นมา = งานเขียนมีลิขสิทธิ์** → **ต้องเขียนใหม่ทั้งหมด** ห้ามคัดลอกประโยค
- ตารางค่าขีดคานะ / ค่าขีดบุชุ = ข้อเท็จจริง (นับได้เอง) → ใช้ได้ แต่ควรตรวจนับเองไม่ก็อปตาราง
- 熊崎式® เป็น **เครื่องหมายการค้าจดทะเบียน** ของสำนัก五聖閣 → **ห้ามใช้คำว่า "熊崎式" เป็นชื่อฟีเจอร์/แบรนด์** ให้ใช้คำสามัญ เช่น "姓名判断 / ทำนายชื่อญี่ปุ่น" แทน

## 8. อะไรที่ยัง "ไม่เจอ" / ต้องหาเพิ่ม (พูดตรง — ห้ามแต่ง)

- ❌ **คำบรรยายความหมายรายเลขครบ 1–81 แบบต้นฉบับที่เชื่อถือได้ (ทางการ)** — ยังไม่ได้ดึงข้อความเต็มทีละเลข (มีแต่ระดับ 吉/凶) ต้องดึงจากแหล่ง (namedic.jp / kseimei.com) ทีละเลข หากจะเขียนคำทำนาย
- ❌ **ตารางขีดคานะครบทุกตัว (46+ ตัว)** — เจอแค่ตัวอย่าง (あいうえお / アイウエオ) ยังไม่ครบทั้งตาราง ต้องดึงเต็มจาก omajinai.co.jp / nekoheat.com / halesia.jp
- ❌ **ตารางขีดคันจิ 旧字体 ครบชุด** — เจอแค่ตัวอย่างบุชุ ต้องอ้าง 康煕字典 / ตารางสำเร็จ (nekoheat 画数表) เมื่อ implement
